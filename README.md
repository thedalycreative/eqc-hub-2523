# EQC Intake 2523 • Web Development Class Hub

Welcome to the **Equinim College 25.23 Web Development** class hub! This is your central resource for course materials, lesson summaries, tools, deadlines, and important announcements.

## 📚 About This Course

A comprehensive web development program covering:
- **Unit 1:** HTML5, CSS3, and responsive design with Bootstrap
- **Unit 2:** Frontend development, wireframing, prototyping, and design tools
- **Unit 3 & 4:** Backend development with JavaScript (starting February 21st with Ryan Jeffrey)

**Duration:** Mondays & Wednesdays, 5:30–8:30pm AWST  
**Graduation:** July 31st, 2026
